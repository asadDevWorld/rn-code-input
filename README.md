# rn-code-input

One-time code and PIN inputs for React Native: animated cells, shake on error, SMS autofill, masked mode, and a lock-screen keypad

## Installation


```sh
npm install rn-code-input
```


## Usage


```js
import { multiply } from 'rn-code-input';

// ...

const result = multiply(3, 7);
```
